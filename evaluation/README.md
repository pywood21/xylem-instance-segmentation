# Evaluation notebooks

This directory contains notebooks for comparing segmentation performance across the three modelling strategies used in the study.

The notebooks aggregate evaluation score CSV files generated from the segmentation pipelines and produce summary tables and comparison figures.

## Purpose

The evaluation notebooks are used to:

- load score CSV files from per-species, mixed-species, and domain-adaptive model outputs;
- compare overall segmentation performance across models;
- summarise metrics such as mean Dice, mean IoU, and accuracy;
- visualise per-class Dice and IoU scores; and
- save comparison figures and summary tables for downstream inspection and manuscript preparation.

## Main notebook

### `00_score_comparison.ipynb`

This notebook compares the segmentation performance of the following model types:

1. per-species models;
2. mixed-species models; and
3. domain-adaptive models.

It assumes that evaluation score CSV files have already been generated by the corresponding inference or evaluation workflows.

## Inputs

The notebook expects score CSV files produced from the segmentation pipelines.

Typical input sources are:

- per-species model score files;
- mixed-species model score files; and
- domain-adaptive model score files.

The exact input paths should be specified in the notebook by setting the score root directories.

Example placeholder:

`SCORE_ROOTS = { ... }`

Users should update these paths according to their local directory structure.

## Outputs

Outputs are saved under:

`evaluation_outputs/`

Typical outputs include:

- `all_model_scores.csv`
- `mean_dice_scores.csv`
- `mean_iou_scores.csv`
- `accuracy_scores.csv`
- `mean_dice.pdf`
- `mean_iou.pdf`
- `accuracy.pdf`
- `per_class_dice_heatmap.pdf`
- `per_class_dice_heatmap.png`
- `per_class_iou_heatmap.pdf`
- `per_class_iou_heatmap.png`

## Notes

This notebook is intended for score aggregation, comparison, and visualisation.

It does not train models. It also assumes that the segmentation predictions and score CSV files have already been generated by the relevant pipeline scripts or original workflow.

For pipeline-specific preprocessing, training, and inference procedures, see:

- `pipelines/per_species/README.md`
- `pipelines/mixed_species/README.md`
- `pipelines/domain_adaptive/README.md`
